# plaza-api — 광장 API + 썸네일

## 먼저 읽을 것

`CONTRACT.md` 2·3절 (스키마가 계약이다), `BRIEF.md` 5절.

## 목표

링크 페이지가 최신 작품 4개를 자동으로 가져갈 수 있게 한다.

**왜 자동이어야 하나:** 수동이면 3개월 뒤엔 갱신을 안 하게 되고,
반년 전 작품 4개가 계속 걸려 있으면 "학원이 안 돌아가나" 하는 인상을 준다.
아이들이 작품을 올릴 때마다 페이지가 알아서 새로워지는 게 이 API의 존재 이유다.

## 소유 파일

```
/api/plaza/best   엔드포인트
썸네일 리사이즈 파이프라인
```

광장 프론트·작품 스키마는 C 소유다. 건드리지 않는다.

---

## 구현 내용

### 엔드포인트

`CONTRACT.md` 2절의 스키마를 정확히 따른다. 필드명을 임의로 바꾸면 A가 깨진다.

```
GET /api/plaza/best?limit=4&mobile=true
```

### 정렬은 `BEST 픽` — 좋아요 수 기준

광장의 BEST 는 좋아요 수로 자동 갱신되므로 사람이 관리할 필요가 없다.
인기 작품이 오래 상위에 남는 것은 정상이며, 아이들이 계속 하고 있다는 뜻이다.

### 에러 시 빈 배열

에러여도 **200 + `[]`** 를 반환한다.
프론트가 실패 분기를 따로 만들 필요 없이 "썸네일 없음" 상태로 떨어지게 하기 위함.

### mobile 파라미터

C의 `mobileSupported` 필드가 준비되기 전까지는 **파라미터를 무시하고 전체 반환**한다.
C 완료 후 필터링을 켠다. C를 기다리지 말 것.

### 썸네일 리사이즈 — 중요

**원본을 그대로 내려주지 않는다.**

- 400px 폭, webp
- 서버에서 미리 생성해 저장 (요청 시 변환 금지)
- 기존 작품 일괄 생성 + 신규 업로드 시 자동 생성

인스타 인앱 브라우저는 일반 브라우저보다 느리다.
원본을 CSS로 줄이면 첫 화면 로딩이 늦어져 그대로 이탈한다.

### 썸네일 없는 작품

기본 이미지를 넣거나 **목록에서 제외**한다.
깨진 이미지가 노출되는 것이 가장 나쁘다.

### CORS

링크 페이지가 같은 도메인(`/link`)에 배포되므로 기본적으로 불필요.
서브도메인 배포로 결정되면 허용 설정 추가.
